# Words and abbreviations

| Word                      | Meaning                                                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **ERP**                   | The sign-in system used to run the Ph.D. programme                                                                   |
| **UGC**                   | University Grants Commission. Its Ph.D. Regulations, 2022 set the national rules the programme follows              |
| **RAB**                   | Research Advisory Board: approves the provisional selection list and the supervisor recognition                      |
| **RAC**                   | Research Advisory Committee of one scholar: the supervisor and members who review the research                        |
| **DC**                    | Doctoral committee meeting (first, confirmation or second, third)                                                    |
| **COE**                   | Controller of Examinations: issues registration numbers and runs the marks of the course-work examination           |
| **Registration number**   | The permanent number of a scholar, issued by the COE; it cannot be changed once recorded                             |
| **Application number**    | The number given on submitting the application, such as SJU/PHD/2026/0158                                            |
| **Batch**                 | A session of admission (for example January 2027). Each batch is a group of scholars                                  |
| **Guide / supervisor**    | The faculty member who guides a scholar. A **co-supervisor** is added for interdisciplinary work                      |
| **Quota**                 | The number of scholars a supervisor may guide at one time (Professor 8, Associate 6, Assistant 4)                    |
| **Vacancy**               | The quota less the scholars the supervisor now guides                                                                |
| **Selection**             | The nine-step admission work on the Selection desk                                                                   |
| **Waiting list**          | Candidates kept in order to fill a seat that falls vacant                                                            |
| **Course work**           | The papers a scholar must pass (at least 12 credits, with Research and Publication Ethics and research methodology) |
| **Hall ticket**           | The permit to write the course-work examination, issued after the fee is approved                                    |
| **RA**                    | Re-appear: the paper is to be written again                                                                          |
| **AAA**                   | Absent for the examination                                                                                           |
| **Passing board**         | The body that approves the course-work results before they are published                                             |
| **Synopsis / thesis**     | The research summary and the final research document                                                                 |
| **Viva**                  | The oral defence of the thesis                                                                                       |
| **Evaluators / examiners**| Outside experts who assess the thesis; the panel is confidential                                                     |
| **Colloquium**            | A session where scholars present and attend; attendance is a requirement                                             |
| **DrillBit**              | The plagiarism-detection software used for the similarity check before the synopsis and before the thesis            |
| **Similarity certificate**| The certificate the Research Office issues after the similarity check                                                |
| **IRINS**                 | Indian Research Information Network System of INFLIBNET: a research profile of publications, projects and patents    |
| **INFLIBNET**             | The UGC's library network; the finished thesis is deposited with it                                                  |
| **Vidwan**                | INFLIBNET's database of experts; supervisors give their Vidwan ID or profile link                                    |
| **ABC ID**                | Academic Bank of Credits identification number                                                                       |
| **NET / SET / GATE**      | National or state eligibility tests that may qualify a candidate for admission or a fellowship                       |
| **SC / ST / OBC (NCL) / EWS** | Reserved categories; a 5% relaxation in marks applies as the UGC decides                                          |
| **NOC**                   | No-objection certificate, from the employer of a part-time scholar                                                   |
| **Stipend**               | The monthly amount for full-time scholars, as notified by the University                                              |
| **Supabase**              | The service that holds the database                                                                                  |
| **Amazon S3**             | The service that holds uploaded files                                                                                |
| **Vercel**                | The service that runs the website online                                                                             |
| **Migration**             | A file of database instructions run once in the Supabase SQL editor                                                  |
| **Backup**                | A saved copy of the data, kept on the Research Office's computer                                                     |
| **SMTP**                  | The mail account the ERP sends mail through                                                                          |
| **Audit trail**           | The log of who did what and when                                                                                     |
